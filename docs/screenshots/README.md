# 截图放置说明

把产品界面截图放进本目录，README 里引用相对路径即可。

## 建议命名

| 文件名 | 内容 |
|---|---|
| `01-generate.png` | 生成面板（素材上传 + 文案 + 进度） |
| `02-workflow.png` | 工作流管理列表 / 表单自动生成 |
| `03-accounts.png` | 账号池与健康检查 |
| `04-vip.png` | 会员中心 / 套餐页 |
| `05-mobile.png` | 移动端面板 |
| `demo.mp4` | 30~60 秒功能演示（可选，建议放 Releases 或外链） |

## 发布前检查

- [ ] 截图中**不得出现**：真实客户用户名、邮箱、API Key、账号密码、订单号
- [ ] 截图中**不得出现**：服务器 IP、后台地址、密钥字段
- [ ] 文案/台词建议用中性示例，避免客户真实素材
- [ ] 图片压缩到 300KB 以内（可用 `pngquant` / `oxipng`）
