# RH工作台 · AI 数字人视频工作流面板

> **本地部署 · 可视化工作流 · 批量生产** —— 面向短视频/直播/自媒体团队的 AI 数字人口播视频生产工具。

本仓库是 **产品展示页**，不包含源码与安装包。产品以授权方式分发。

---

## 这是什么

RH工作台是一套跑在 **Windows 本机** 的 AI 数字人视频生产工作台。打开面板即可：

- 上传形象/音色素材，输入文案 → 自动生成数字人口播视频
- 用可视化表单配置 ComfyUI 工作流，导入即用、热更新
- 管理国际站账号池，批量排队生成，成品自动归档
- 授权、会员、版本更新由云端统一管控，开箱即用

**数据不出本机**：视频素材、生成结果、账号配置全部保存在客户自己的电脑上。

## 技术架构

```
┌───────────────────────────────┐         ┌────────────────────────────┐
│        客户机（Windows）        │         │        云端控制面           │
│                               │         │                            │
│  ┌─────────────────────────┐  │         │  ┌──────────────────────┐  │
│  │ RH工作台.exe             │  │  HTTPS  │  │ 授权校验 / 会员管理   │  │
│  │  ├ 本地面板 (FastAPI)    │◄─┼────────►│  │ 版本分发（签名校验）  │  │
│  │  ├ 工作流引擎            │  │         │  │ 账号池 / 用户登记     │  │
│  │  ├ 账号池（本地加密）    │  │         │  └──────────────────────┘  │
│  │  └ 渲染 / 合成管线       │  │         │                            │
│  └─────────────────────────┘  │         └────────────────────────────┘
│                               │
│  CosyVoice2 · ComfyUI ·      │
│  Wav2Lip · LatentSync · Sonic │
└───────────────────────────────┘
```

- **后端**：Python 3 / FastAPI / uvicorn
- **前端**：原生 HTML/CSS/JS，深色主题，桌面 + 移动双端
- **AI 引擎**：CosyVoice2（TTS）、Wav2Lip / LatentSync / Sonic（唇形）、ComfyUI（工作流）
- **视频处理**：ffmpeg / OpenCV / PyTorch
- **分发形态**：单文件 EXE，内置运行时，双击即用

## 常见问题

**Q：需要联网吗？**
A：本地生成不需要外网；授权校验、会员同步、版本更新需要联网。云端不可达时不影响已授权客户的本机使用。

**Q：数据会上传吗？**
A：素材、成品、账号配置均保存在本机。仅授权与版本信息与云端交互。

**Q：支持批量吗？**
A：支持多任务排队与批量生成，成品自动归档，可整批下载。
